# BioSync Monitor V1.0
This project is a compact Arduino-based health monitoring system that measures two essential vital signs: heart rate (BPM) and body temperature (BBT). Using the MAX30102 pulse sensor and the LM35 temperature sensor.

# 🔹Features
- Accurate heart rate monitoring (BPM)
- Continuous body temperature measurement (°C)
- Clean real-time OLED display visualization
- Low-power & beginner-friendly hardware design

# 🔹Components
- Arduino UNO
- Oled Display 128x64
- MAX30102
- LM35
- Jumper Wires
- Breadboard
- Buzzer

# 🔹Libraries
- [SparkFun_MAX3010x_Sensor_Library](https://github.com/sparkfun/SparkFun_MAX3010x_Sensor_Library)
- [Adafruit_SSD1306](https://github.com/adafruit/Adafruit_SSD1306)
